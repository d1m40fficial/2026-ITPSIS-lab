# МДК.06.02 — лабораторные работы

Практикум обновлён на основе 2026-lab-shablone (6ff36d1). Сохранены 12 официальных работ и 29 предметных областей, распределённых по шести группам вариантов (5/5/5/5/5/4). Баллы на сайте не публикуются, но хранятся в данных и используются при оценивании.

В каждой работе есть связь с соответствующими лекциями, локальная опора ITIL 4, отдельный пример DEMO, новые контрольные условия своего варианта, шесть обязательных шагов и критерии. Word-формы различаются по результату работы и не содержат внешних ссылок или чек-листов.

Сайт: https://olgakraven.github.io/2026-ITPSIS-lab/
Лекции: https://olgakraven.github.io/2026-ITPSIS-lecture/

## Использование

Выберите вариант в каталоге и откройте работу: при необходимости введите код преподавателя. Скачивание доступно на странице работы — кнопкой «Скачать лабораторную работу» и отдельно шаблон DOCX. Готовые преподавательские ZIP со всеми работами и 29 вариантами лежат по прямым адресам `teacher-packs/*.zip`. Сдача — один заполненный DOCX преподавателю. Кнопка «?» открывает инструкцию.

## Разработка

Node.js 24 и pnpm 11. Выполните pnpm install --frozen-lockfile, затем pnpm dev. Проверки: pnpm run check и pnpm run test:e2e.

Канонические условия: src/data/labs.json. Вариантные исходные разделы: src/data/variant-data.json. Механизм resolveLab используется страницей и экспортом; не меняйте данные только в одном представлении. Версия: 2026-09-12-lab-itil-1.

Формы: inputs/report-forms.json, сохранённые эталоны в inputs/report-reference. Команда pnpm run generate:reports требует Python с lxml. После неё откройте и визуально проверьте все DOCX. Старый генератор содержания отключён, чтобы не перезаписывать новую редакцию.

Команда pnpm run generate:subjects обновляет совместимые архивы только исходных данных по прежним URL. Полные автономные комплекты собирает интерфейс через src/lib/labPackage.ts. После изменения инструкции выполните pnpm run generate:guide.

Отдельные папки `inputs/subject-areas/semester-7` и `inputs/subject-areas/semester-8` сгруппированы по лабораторным. В каждой лабораторной лежат все 29 вариантов. Обе папки пересобираются командой `pnpm run generate:subjects`.

Доступ по коду работает как в лекциях: коды преподавателя лежат в непубликуемом `config/access-codes.json`, сборка `pnpm run compile:access` кладёт в `public/access-codes.json` только SHA-256 хеши. Подробности в `docs/ACCESS_CODES.md`.

Сопровождение преподавателя и ключи передаются отдельно; они не входят в сайт и студенческие ZIP. Утверждённая полная РПД не предоставлена. Оценка нагрузки требует проверки на реальной группе.
