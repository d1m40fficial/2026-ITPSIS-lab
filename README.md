# МДК.06.02 — лабораторные работы

Статический практикум по МДК.06.02 «Инженерно-техническая поддержка сопровождения информационных систем». Двенадцать работ образуют последовательный цикл сопровождения: результат предыдущей работы становится входом следующей.

## Состав

- 7 семестр: 7 работ по организации сопровождения и службы поддержки, 50 баллов;
- 8 семестр: 5 работ по выявлению и устранению отказов, 50 баллов;
- суммарно: 12 работ и 100 баллов;
- 30 сквозных предметных областей, объединённых в шесть групп по пять вариантов;
- пять характеристик сопровождения общие для вариантов внутри одной группы;
- для каждого варианта доступен отдельный ZIP только с его исходными данными;
- в каждой работе есть разобранный пример на отдельной демонстрационной системе;
- обязательная часть состоит из шести последовательных шагов с исходными данными, результатом и способом проверки;
- дополнительное задание отделено от обязательных действий и не влияет на их полноту;
- для каждой работы подготовлен редактируемый шаблон отчёта Word;
- сдача выполняется только в [LMS](https://lms.synergy.ru/) одним файлом `.docx`.

Продолжительность отдельных работ на сайте и в шаблонах не публикуется. Объём и сложность заданий выстроены по учебной последовательности дисциплины.

## Локальный запуск

Требуются Node.js 22+ и pnpm 11.

```bash
pnpm install
pnpm run generate:labs
pnpm run generate:subjects
pnpm dev
```

Полная проверка проекта:

```bash
pnpm run check
pnpm run test:e2e
```
