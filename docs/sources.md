- задания выполняются только на выданных учебных карточках, журналах и симуляциях;
- каждая предметная область имеет собственный изолированный пакет данных;
- продолжительность отдельной лабораторной работы не публикуется;
- искусственный интеллект не является обязательным инструментом;
- на сайте нет загрузки отчётов, авторизации студентов и автоматической проверки;
- отчёт сдаётся одним файлом `.docx` только через [LMS](https://lms.synergy.ru/).
