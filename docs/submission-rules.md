# Правила сдачи лабораторной работы

1. Откройте нужную лабораторную работу на сайте и, если она закрыта, введите код преподавателя.
2. Скачайте шаблон отчёта на странице работы или кнопкой «Скачать лабораторную работу».
3. Сохраните копию под именем `Фамилия_Группа_МДК0602_ЛРN.docx`, где `N` — сквозной номер работы с двумя цифрами.
4. Заполните титульный лист, таблицы результатов, обоснование, контрольные проверки, доказательства, самопроверку и краткий вывод.
5. Удалите серые служебные подсказки, которые не относятся к вашему результату.
6. Оформите документ под нормоконтроль: проверьте поля, размеры, подписи и нумерацию.
7. Проверьте, что рисунки читаемы, подписи совпадают с таблицами, а персональные данные и реальные секреты отсутствуют.
8. Покажите один итоговый файл `.docx` преподавателю.

Сайт используется только как учебный стенд и источник шаблона. Загрузка файла на сайт не предусмотрена.
