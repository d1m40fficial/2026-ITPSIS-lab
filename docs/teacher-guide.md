# Руководство преподавателя

## Перед выдачей курса

1. Проверьте формулировки и последовательные связи в `src/data/labs.json`.
2. Проверьте ссылку на LMS в `src/config.ts`.
3. Убедитесь, что в настройках репозитория GitHub Pages выбран источник GitHub Actions.
4. Запустите `pnpm run check` и `pnpm run test:e2e`.
5. После публикации откройте маршруты вида `#/lab/7-01` и `#/lab/8-01`, затем проверьте скачивание DOCX и ZIP своего варианта.

## Обновление содержания

Сначала измените `scripts/generate_labs.py`, затем выполните:

```bash
pnpm run generate:labs
pnpm run generate:subjects
python scripts/generate_reports.py
pnpm run check
```

Поля `sequenceInput` и `sequenceOutput` фиксируют передачу результата между работами. Не удаляйте их и не заменяйте общими фразами: студент должен понимать, какой ранее созданный артефакт применяется дальше.

Шаблоны Word создаются из утверждённого титульного листа. Исходный эталон остаётся неизменным; рабочая часть добавляется после титульной страницы.

## Безопасные границы

Работы рассчитаны на учебные данные и локальные симуляции. Они не требуют действий в производственной системе, обработки реальных секретов или публикации персональных данных.
