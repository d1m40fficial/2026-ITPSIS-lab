# 7 семестр

В каждой папке лабораторной работы собраны все 30 вариантов.

## Состав

- `LR01` — Разработка регламента работы службы поддержки информационной системы (30 вариантов)
- `LR02` — Разработка соглашения об уровне обслуживания с показателями и приоритетами (30 вариантов)
- `LR03` — Обработка потока обращений пользователей: регистрация, классификация, назначение приоритета и исполнителя (30 вариантов)
- `LR04` — Воспроизведение проблемы по описанию пользователя и составление сценария воспроизведения (30 вариантов)
- `LR05` — Разработка статей базы знаний по типовым обращениям пользователей (30 вариантов)
- `LR06` — Разработка регламента обновления системы с порядком отката и проведение учебного обновления (30 вариантов)
- `LR07` — Разработка регламента резервного копирования и восстановления информационной системы (30 вариантов)
