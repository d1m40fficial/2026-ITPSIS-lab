# 8 семестр

В каждой папке лабораторной работы собраны все 30 вариантов.

## Состав

- `LR01` — Отработка порядка действий при отказе информационной системы по заданному сценарию (30 вариантов)
- `LR02` — Организация сбора сведений об ошибках: настройка ведения журнала приложения и разбор записей (30 вариантов)
- `LR03` — Локализация отказа по слоям: определение неисправного слоя по заданным признакам (30 вариантов)
- `LR04` — Разбор отказа: восстановление хронологии по журналам, определение причины, оформление отчёта (30 вариантов)
- `LR05` — Составление плана технического обслуживания аппаратных средств и ведение учёта состояния оборудования (30 вариантов)
