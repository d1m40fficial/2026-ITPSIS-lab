# SA04 · 7 семестр · ЛР 01 · Разработка регламента работы службы поддержки информационной системы

**Предметная область:** Электронная библиотека
**Система:** `ITPSIS-SA04`
**Критичная функция:** поиск и открытие учебных изданий
**Профиль:** Публичные сервисы первой линии (варианты 01–05)

## Рабочая ситуация

Для системы «Электронная библиотека» требуется запустить управляемую службу поддержки. Обращения сейчас поступают по разным каналам, ответственность не закреплена, а результат решения фиксируется неполно.

## Пять характеристик профиля

| Код | Характеристика | Значение |
| --- | --- | --- |
| C1 | Режим поддержки | P1 — круглосуточно; остальные — 08:00–20:00 |
| C2 | Цель реакции | P1 — 10 минут; P2 — 30 минут |
| C3 | Цель восстановления | P1 — 60 минут; P2 — 4 часа |
| C4 | Порог эскалации | P1 — сразу; P2 — через 45 минут |
| C5 | Хранение доказательств | оперативные записи — 180 дней |

## Исходные данные

Работайте только с данными выбранной предметной области. Все организации, пользователи, адреса, события и показатели являются учебными и не относятся к реальным системам.

### Паспорт службы

Система: ITPSIS-SA04. Критичная функция: поиск и открытие учебных изданий.

Пользователи работают по будням с 08:00 до 20:00; дежурная связь предусмотрена только для критичных отказов.

Каналы: портал, телефон и служебная почта. Чат используется только для уточнений после регистрации.

### Участники и ограничения

| Роль | Доступно | Ограничение |
| --- | --- | --- |
| Диспетчер L1 | 2 специалиста | Не изменяет конфигурацию |
| Инженер L2 | 2 специалиста | Работает по назначенной карточке |
| Команда разработки L3 | по эскалации | Нужен воспроизводимый сценарий |
| Владелец сервиса | 1 человек | Согласует критичные изменения |
| Администратор БД | по запросу | Нужен номер обращения |

### Проблемы текущего процесса

| ID | Наблюдение | Последствие |
| --- | --- | --- |
| P01 | Телефонный звонок не зарегистрирован | Нет истории решения |
| P02 | L1 передал снимок экрана без окружения | L2 повторно собирал сведения |
| P03 | Карточка закрыта без подтверждения | Пользователь открыл повторное обращение |
| P04 | Критичный отказ отправлен общей почтой | Оповещение задержалось |
| P05 | Решение найдено, статья не создана | Следующая смена повторила диагностику |
