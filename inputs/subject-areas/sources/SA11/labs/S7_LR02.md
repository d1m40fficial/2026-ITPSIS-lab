# SA11 · 7 семестр · ЛР 02 · Разработка соглашения об уровне обслуживания с показателями и приоритетами

**Предметная область:** Шина интеграции LMS
**Система:** `ITPSIS-SA11`
**Критичная функция:** доставка событий между учебными системами
**Профиль:** Учётные и интеграционные сервисы (варианты 11–15)

## Рабочая ситуация

Владелец системы «Шина интеграции LMS» и служба поддержки по-разному оценивают срочность обращений. Требуется согласовать измеримые обязательства для системы ITPSIS-SA11, не обещая показатели, которые команда не сможет подтвердить.

## Исходные данные

Работайте только с данными выбранной предметной области. Все организации, пользователи, адреса, события и показатели являются учебными и не относятся к реальным системам.

### Условия обслуживания

Система: ITPSIS-SA11. Критичная функция: доставка событий между учебными системами.

Рабочее окно: 08:00–20:00 по будням. Для P1 действует дежурный канал круглосуточно.

Плановые работы, заранее согласованные владельцем, не включаются в расчёт доступности.
