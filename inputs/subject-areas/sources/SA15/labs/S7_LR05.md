# SA15 · 7 семестр · ЛР 05 · Разработка статей базы знаний по типовым обращениям пользователей

**Предметная область:** Компьютерный класс
**Система:** `ITPSIS-SA15`
**Критичная функция:** вход пользователя и запуск учебной среды
**Профиль:** Учётные и интеграционные сервисы (варианты 11–15)

## Рабочая ситуация

За месяц по системе «Компьютерный класс» накопились повторяющиеся обращения. Решения известны отдельным специалистам, но пользователи и новая смена поддержки не могут применить их без дополнительных уточнений.

## Место в последовательности

**Результаты предыдущих работ:** Классифицированный реестр из ЛР 3 и проверенный сценарий воспроизведения из ЛР 4.

**Материалы на входе:** Статистика K01–K06, требования к публикации, версия системы и неудачный черновик статьи.

**Использование результата:** Проверяемые инструкции базы знаний используются как контрольные операции при учебном обновлении в ЛР 6.

Плановый пересмотр — раз в 90 дней и после каждого изменения интерфейса.
