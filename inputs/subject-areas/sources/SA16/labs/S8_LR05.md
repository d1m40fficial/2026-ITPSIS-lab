# SA16 · 8 семестр · ЛР 05 · Составление плана технического обслуживания аппаратных средств и ведение учёта состояния оборудования

**Предметная область:** Компьютерный класс
**Система:** `ITPSIS-SA16`
**Критичная функция:** вход пользователя и запуск учебной среды
**Профиль:** Автоматизированные рабочие места (варианты 16–20)

## Рабочая ситуация

Аппаратные компоненты системы «Компьютерный класс» обслуживаются реактивно. Требуется сформировать единый реестр состояния и спланировать работы с учётом критичности, наблюдаемых признаков и допустимых окон.

## Пять характеристик профиля

| Код | Характеристика | Значение |
| --- | --- | --- |
| C1 | Режим поддержки | по расписанию учебных площадок |
| C2 | Цель реакции | P1 — 20 минут; P2 — 2 часа |
| C3 | Цель восстановления | P1 — 4 часа; P2 — следующий рабочий день |
| C4 | Порог эскалации | после двух безуспешных проверок L1 |
| C5 | Хранение доказательств | карточки — 90 дней; состояние — 30 дней |

Для каждого обслуживания требуется запись состояния до и после работы.
