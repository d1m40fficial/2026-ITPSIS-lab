# SA17 · 7 семестр · ЛР 05 · Разработка статей базы знаний по типовым обращениям пользователей

**Предметная область:** Рабочее место преподавателя
**Система:** `ITPSIS-SA17`
**Критичная функция:** доступ к учебным материалам и ведомостям
**Профиль:** Автоматизированные рабочие места (варианты 16–20)

## Рабочая ситуация

За месяц по системе «Рабочее место преподавателя» накопились повторяющиеся обращения. Решения известны отдельным специалистам, но пользователи и новая смена поддержки не могут применить их без дополнительных уточнений.

## Пять характеристик профиля

| Код | Характеристика | Значение |
| --- | --- | --- |
| C1 | Режим поддержки | по расписанию учебных площадок |
| C2 | Цель реакции | P1 — 20 минут; P2 — 2 часа |
| C3 | Цель восстановления | P1 — 4 часа; P2 — следующий рабочий день |
| C4 | Порог эскалации | после двух безуспешных проверок L1 |
| C5 | Хранение доказательств | карточки — 90 дней; состояние — 30 дней |

## Исходные данные

Работайте только с данными выбранной предметной области. Все организации, пользователи, адреса, события и показатели являются учебными и не относятся к реальным системам.

### Требования к публикации

Система: ITPSIS-SA17. Текущая версия: 2.6.1.

Пользовательская статья не может содержать административные команды, реальные адреса или секреты.

Статьи K04 и K05 доступны только сотрудникам поддержки и должны завершаться эскалацией.

Плановый пересмотр — раз в 90 дней и после каждого изменения интерфейса.
