# SA25 · 7 семестр · ЛР 01 · Разработка регламента работы службы поддержки информационной системы

**Предметная область:** Узел мониторинга
**Система:** `ITPSIS-SA25`
**Критичная функция:** сбор метрик и формирование сигналов
**Профиль:** Сетевые и защитные сервисы (варианты 21–25)

## Рабочая ситуация

Для системы «Узел мониторинга» требуется запустить управляемую службу поддержки. Обращения сейчас поступают по разным каналам, ответственность не закреплена, а результат решения фиксируется неполно.

## Место в последовательности

**Результаты предыдущих работ:** Не требуются: работа открывает последовательность и создаёт организационную основу сопровождения.

**Материалы на входе:** Паспорт выбранной системы, режим и каналы поддержки, таблица участников и наблюдения P01–P05.

**Использование результата:** Регламент и матрица ролей используются в ЛР 2 для определения сторон, ответственности и рабочего окна SLA.

## Пять характеристик профиля

| Код | Характеристика | Значение |
| --- | --- | --- |
| C1 | Режим поддержки | круглосуточно |
| C2 | Цель реакции | P1 — 5 минут; P2 — 20 минут |
| C3 | Цель восстановления | P1 — 45 минут; P2 — 3 часа |
| C4 | Порог эскалации | при потере резервирования или повторном отказе |
| C5 | Хранение доказательств | конфигурации и события — 365 дней |

## Исходные данные

Работайте только с данными выбранной предметной области. Все организации, пользователи, адреса, события и показатели являются учебными и не относятся к реальным системам.

### Паспорт службы

Система: ITPSIS-SA25. Критичная функция: сбор метрик и формирование сигналов.

Пользователи работают по будням с 08:00 до 20:00; дежурная связь предусмотрена только для критичных отказов.

Каналы: портал, телефон и служебная почта. Чат используется только для уточнений после регистрации.

### Рамки договора сопровождения

Заказчик учебной услуги — владелец сервиса; исполнитель — служба поддержки.

В сопровождение входят регистрация обращений, консультации, диагностика, восстановление и ведение базы знаний. Разработка новых функций оформляется отдельным изменением.

Результат услуги подтверждается записью в карточке обращения и проверкой критичной функции.

### Участники и ограничения

| Роль | Доступно | Ограничение |
| --- | --- | --- |
| Первая линия поддержки (L1) | 2 специалиста | Не изменяет конфигурацию |
| Вторая линия поддержки (L2) | 2 специалиста | Работает по назначенной карточке |
| Третья линия поддержки (L3) | по эскалации | Нужен воспроизводимый сценарий |
| Владелец сервиса | 1 человек | Согласует критичные изменения |
| Администратор БД | по запросу | Нужен номер обращения |

### Проблемы текущего процесса

| ID | Наблюдение | Последствие |
| --- | --- | --- |
| P01 | Телефонный звонок не зарегистрирован | Нет истории решения |
| P02 | L1 передал снимок экрана без окружения | L2 повторно собирал сведения |
| P03 | Карточка закрыта без подтверждения | Пользователь открыл повторное обращение |
| P04 | Критичный отказ отправлен общей почтой | Оповещение задержалось |
| P05 | Решение найдено, статья не создана | Следующая смена повторила диагностику |
