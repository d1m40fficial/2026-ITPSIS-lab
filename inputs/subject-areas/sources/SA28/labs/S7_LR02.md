# SA28 · 7 семестр · ЛР 02 · Разработка соглашения об уровне обслуживания с показателями и приоритетами

**Предметная область:** Служба идентификации
**Система:** `ITPSIS-SA28`
**Критичная функция:** проверка учётной записи и выдача сеанса
**Профиль:** Критичные сервисы данных и доступа (варианты 26–30)

## Рабочая ситуация

Владелец системы «Служба идентификации» и служба поддержки по-разному оценивают срочность обращений. Требуется согласовать измеримые обязательства для системы ITPSIS-SA28, не обещая показатели, которые команда не сможет подтвердить.

## Исходные данные

Работайте только с данными выбранной предметной области. Все организации, пользователи, адреса, события и показатели являются учебными и не относятся к реальным системам.

### Условия обслуживания

Система: ITPSIS-SA28. Критичная функция: проверка учётной записи и выдача сеанса.

Рабочее окно: 08:00–20:00 по будням. Для P1 действует дежурный канал круглосуточно.

Плановые работы, заранее согласованные владельцем, не включаются в расчёт доступности.
