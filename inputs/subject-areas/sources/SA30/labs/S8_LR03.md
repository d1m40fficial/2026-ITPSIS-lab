# SA30 · 8 семестр · ЛР 03 · Локализация отказа по слоям: определение неисправного слоя по заданным признакам

**Предметная область:** Хранилище результатов аттестации
**Система:** `ITPSIS-SA30`
**Критичная функция:** запись и выдача подтверждённых результатов
**Профиль:** Критичные сервисы данных и доступа (варианты 26–30)

## Рабочая ситуация

Критичная операция системы «Хранилище результатов аттестации» недоступна части пользователей. Отдельные компоненты отвечают, поэтому требуется последовательно проверить рабочее место, сеть, приложение, сервер и базу данных.

## Пять характеристик профиля

| Код | Характеристика | Значение |
| --- | --- | --- |
| C1 | Режим поддержки | круглосуточно с дежурной сменой |
| C2 | Цель реакции | P1 — 5 минут; P2 — 15 минут |
| C3 | Цель восстановления | P1 — 30 минут; P2 — 2 часа |
| C4 | Порог эскалации | P1 сразу владельцу и техническому руководителю |
| C5 | Хранение доказательств | решения и технические журналы — 365 дней |

## Исходные данные

Работайте только с данными выбранной предметной области. Все организации, пользователи, адреса, события и показатели являются учебными и не относятся к реальным системам.

### Симптом

Система: ITPSIS-SA30. Критичная функция: запись и выдача подтверждённых результатов.

Пользователи площадки A получают тайм-аут; площадка B работает. Проблема началась в 13:20 после планового изменения сетевого маршрута.

Изменять рабочую конфигурацию запрещено; доступны только приведённые результаты проверок.
