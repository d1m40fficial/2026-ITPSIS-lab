# SA30 · 8 семестр · ЛР 04 · Разбор отказа: восстановление хронологии по журналам, определение причины, оформление отчёта

**Предметная область:** Хранилище результатов аттестации
**Система:** `ITPSIS-SA30`
**Критичная функция:** запись и выдача подтверждённых результатов
**Профиль:** Критичные сервисы данных и доступа (варианты 26–30)

## Рабочая ситуация

После восстановления системы «Хранилище результатов аттестации» участники по-разному описывают причину отказа. Необходимо объединить журналы, отделить факты от предположений и подготовить профессиональный отчёт без поиска виновного.

## Исходные данные

Работайте только с данными выбранной предметной области. Все организации, пользователи, адреса, события и показатели являются учебными и не относятся к реальным системам.

### Источники времени

Система: ITPSIS-SA30. Критичная функция: запись и выдача подтверждённых результатов.

Web и мониторинг используют UTC+3; API и DB — UTC. Погрешность синхронизации не более 3 секунд.

Восстановление завершено; реальные изменения выполнять не требуется.
